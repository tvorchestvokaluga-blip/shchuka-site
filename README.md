# Сайт художественной школы «Щука», Калуга

Статический сайт: HTML, CSS и JavaScript без сборки и без бэкенда.
Домен — [хшщкалуга.рф](https://xn--80aai0ag2ckyj.xn--p1ai/)

## Структура

```
index.html      главная
policy.html     политика обработки персональных данных
sveden.html     сведения об образовательной организации
robots.txt      инструкция поисковым роботам
sitemap.xml     карта сайта
CNAME           домен для GitHub Pages
images/         логотип, фавикон, фотографии
docs/           выписка из реестра лицензий
```

Стили и скрипты встроены в HTML — сборка не нужна, npm не нужен.
Любой файл можно открыть двойным кликом и посмотреть в браузере.

## Как внести правку

1. Открыть нужный файл на GitHub
2. Нажать на карандаш (Edit this file)
3. Поменять текст
4. Commit changes

Сайт пересоберётся сам за одну-две минуты.

## Что ещё не подключено

- **Приём заявок с формы.** Форма проверяет данные и показывает подтверждение,
  но никуда не отправляет. Место отмечено в `index.html` комментарием
  `ПОДКЛЮЧЕНИЕ ЗАЯВОК`.
- **Фотографии галереи** пока грузятся с CDN Tilda. При отключении Tilda
  их нужно скачать и положить в `images/`.
